# Overview

ResultNotify is a full-stack result tracking platform designed for Mumbai University students.

The project focuses on:

* Fast result searching
* Dynamic filtering systems
* Responsive mobile-first design
* Modern routing architecture
* Clean reusable component structure
* Scalable frontend & backend setup
* PDF result access
* Better UI experience than traditional university portals

# Features Implemented

## Dynamic Result Search

The platform currently supports:

* Live searching
* Search normalization
* Fast filtering
* Course-based search
* Semester filtering
* Year filtering
* Pattern filtering

Search architecture was optimized to support future Fuse.js integration.

---

## Routing System

Implemented using React Router DOM.

### Current Supported Routes

```bash
/
/page/:pageNumber
```

### Implemented Routing Features

* Dynamic route support
* URL-based navigation
* Shareable result pages
* Route fallback handling
* Custom 404 page
* Reusable routing structure
* Component-based navigation system

### Current Status

Pagination route structure is currently implemented and under active optimization.

The project already supports route-based page navigation architecture for future scalable pagination improvements.

* Reusable route structure

---

## Custom 404 System

A fully designed custom Not Found page was implemented.

Features:

* Same UI theme as homepage
* Shared Navbar component
* Shared Footer component
* Mobile responsive layout
* Styled navigation back button

# Local Development Setup

## Clone Repository

```bash
git clone https://github.com/yourusername/resultnotify.git
```

---

## Install Frontend Dependencies

```bash
cd client
npm install
```

---

## Install Backend Dependencies

```bash
cd server
npm install
```

---

## Run Frontend

```bash
npm run dev
```

---

## Run Backend

```bash
node server.js
```
